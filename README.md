# xali's Enchanted Books Reforged
This is one of my favorite resource packs, but unfortunately it's missing some features, and is broken in some modpacks in the current version. I want to mantain this pack so I can keep it for myself, and for others fans of xali's work. I will likely take this down as soon as xali supports it again, but until then I will use their license to do it myself.

Trying to find the enchanted book I wanted in a chest full of it have always been a pain to me. This pack aim to resolve that issue by giving every enchanted book a different texture base on their type and their level while keeping an art style that still fit into the base game.
## Supported Enchants
- All as of version 26.3, including Lunge.

I do not include any of the mod support that xalixilax does in the original pack. If you desire those, the original pack is still mostly functional in the current version, and I'd advise you go use that instead. 
## Requirement
****None!**** This pack uses the vanilla CIT support introduced in recent updates. It's fully functional in a vanilla installation.

### Known Issues

- Pack labeled "Broken or Incompatible" on modern versions

Due to recent overhauls in the resource pack format, there is no way to avoid this error without making the pack incompatible with versions before the change without making multiple versions. There's nothing actually wrong with the pack, just ignore the warning and proceed.
